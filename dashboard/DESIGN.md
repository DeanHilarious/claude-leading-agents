# 指挥台 Dashboard · 设计稿

一个本地只读网站，把 `claude-leading-agents` 的协作过程画出来：Claude 派了哪些活、谁在做、做到哪、返工几轮、花了多少 token。

## 1. 设计方向

**「夜间指挥台」**：深色、安静、信息密度高，但不像监控大屏那样吵。参考 Linear、Vercel、Raycast 的克制感：
- 大面积留白和细边框，几乎不用阴影；用**颜色只标记身份和状态**，其余一律灰阶。
- 三个角色各有一个专属色，全站一致：看到珊瑚色就是 Claude，蓝紫是 Codex，青绿是 CodeBuddy。
- 动效只用来表达「正在发生」：运行中的连线有流动的虚线，运行中的状态点有呼吸光。静止的东西绝不动。
- 默认深色，提供浅色主题（跟随系统，可手动切换）。

## 2. 设计令牌（CSS 变量，写在 `:root`）

### 颜色 · 深色（默认）
| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0C10` | 页面底色 |
| `--bg-grid` | `rgba(255,255,255,.035)` | 流程画布的点阵网格 |
| `--surface` | `#13151B` | 卡片、侧栏 |
| `--surface-2` | `#1A1D25` | 悬停、输入框、代码块 |
| `--border` | `rgba(255,255,255,.07)` | 默认边框 |
| `--border-strong` | `rgba(255,255,255,.14)` | 悬停/选中边框 |
| `--text` | `#ECEDF1` | 正文 |
| `--text-2` | `#9A9EAB` | 次要文字 |
| `--text-3` | `#5E6270` | 标签、时间戳 |
| `--claude` | `#E8876A` | Claude（珊瑚） |
| `--codex` | `#8E9BFF` | Codex（蓝紫） |
| `--codebuddy` | `#3DD6B5` | CodeBuddy（青绿） |
| `--running` | `#F5B544` | 运行中（琥珀） |
| `--review` | `#8E9BFF` | 待验收（与 Codex 同色系，但总配文字标签） |
| `--passed` | `#4ADE80` | 已通过 |
| `--rework` | `#FB923C` | 返工中 |
| `--failed` | `#F87171` | 中断/放弃 |
| `--idle` | `#5E6270` | 已结束/未知 |

每个角色色和状态色都要有一个 12% 透明度的「淡底」版本，例如 `--codex-soft: rgba(142,155,255,.12)`，用作徽章和泳道底色。

### 颜色 · 浅色
`--bg #F7F7F9`、`--surface #FFFFFF`、`--surface-2 #F1F2F5`、`--border rgba(15,17,23,.08)`、`--border-strong rgba(15,17,23,.16)`、`--text #12131A`、`--text-2 #5B5F6B`、`--text-3 #9094A0`、`--bg-grid rgba(15,17,23,.05)`。角色色和状态色加深一档以保证对比度：`--claude #D0623F`、`--codex #5B6CF0`、`--codebuddy #0FA888`、`--running #D48A06`、`--passed #16A34A`、`--rework #EA6A0A`、`--failed #DC2626`。

### 字体
- 正文：`"Inter", -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 等宽（日志、路径、数字明细）：`"JetBrains Mono", "SF Mono", ui-monospace, Menlo, monospace`
- 不引用任何外部字体文件，装了就用，没装就回落。
- 所有数字 `font-variant-numeric: tabular-nums`。

| 级别 | 字号/行高/字重 | 用途 |
|---|---|---|
| display | 28/36/600，字距 -0.02em | 页面标题 |
| title | 16/24/600 | 卡片标题、面板标题 |
| body | 14/22/400 | 正文 |
| small | 12/18/500 | 标签、徽章、时间 |
| micro | 11/16/600，大写字距 0.06em | 分组小标题（如「进行中」） |
| stat | 32/36/600 等宽 | 统计数字 |

### 尺寸
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 圆角：徽章 6，卡片 12，面板/抽屉 16，状态点和头像全圆。
- 边框统一 1px。阴影只在浮层（抽屉、提示框）用：`0 24px 48px -12px rgba(0,0,0,.5)`。
- 动效时长 160ms（悬停）/ 240ms（抽屉、展开），曲线 `cubic-bezier(.2,.8,.2,1)`。`prefers-reduced-motion` 时关掉所有循环动画。

## 3. 布局

```
┌──────┬──────────────────────────────────────────────────────┐
│ 侧栏  │ 顶栏：面包屑 ·························· 额度环 · 主题切换 │
│ 64px │──────────────────────────────────────────────────────│
│ ◎ 标志│                                                      │
│ ▦ 总览│                 主内容区（最大宽 1440，居中）            │
│ ¥ 账单│                                                      │
│      │                                                      │
│ ● 实时│                                                      │
└──────┴──────────────────────────────────────────────────────┘
```
- **侧栏**：64px 宽，只放图标（悬停出现文字提示）。顶部是标志：一个珊瑚色圆点向外连出蓝紫、青绿两个小点（1 个大脑 + 2 双手），用 SVG 画。底部有一个「实时」指示灯：SSE 连上为绿色呼吸点，断开为灰色。
- **顶栏**：56px 高，左侧面包屑（`总览 / oc102`），右侧是 Codex 周额度环（直径 28px 的环形进度，旁边写 `69% · 10/22 重置`；>70% 环变琥珀，>90% 变红）和主题切换按钮。
- 窄屏（<900px）：侧栏变成底部标签栏，看板变成单列。

## 4. 页面

### 4.1 总览 `#/`
1. **标题行**：`指挥台`（display）+ 一行副标题「Claude 派出的所有任务」。
2. **统计条**：4 个并排的统计卡（卡片无边框，只有 `--surface` 底）：
   - 进行中的任务 / 正在跑的代理（数字旁一个琥珀呼吸点）
   - 待验收的子任务
   - 返工率（有返工的子任务 ÷ 全部子任务，近 7 天）
   - 本周 token（Codex 与 CodeBuddy 分开，用两段细条表示占比，颜色用角色色）
3. **看板**：三列 `进行中` / `待验收` / `已结束`，列标题用 micro 字号 + 数量。每张**任务卡**：
   ```
   ┌────────────────────────────────────┐
   │ oc102                    ● 运行中    │  ← 任务名（title）+ 状态徽章
   │ 移植：压缩完全交给 Runtime …          │  ← 第一份规格的一级标题，单行省略
   │                                    │
   │ ▮▮▮▮▯▯  6 个子任务                   │  ← 子任务状态条：每个子任务一格，填状态色
   │ ◉ Codex 4   ◉ CodeBuddy 2   ↻ 3    │  ← 按代理计数（角色色圆点）+ 返工总轮数
   │ 10/16 21:29 · 23 小时 · 1.2M tok    │  ← 开工时间、耗时、token（text-3）
   └────────────────────────────────────┘
   ```
   悬停：边框变 `--border-strong`，卡片上移 1px。点击进入详情。「已结束」列默认只显示最近 12 个，底部有「显示全部」。
4. 顶部右侧一个搜索框（按任务名、规格标题过滤）。

### 4.2 任务详情 `#/run/<任务名>`
1. **头部**：任务名（display）+ 状态徽章；下面一行元信息：开工时间 · 耗时 · 子任务数 · 返工轮数 · token 总量；右侧「打开文件夹路径」（只显示路径，点击复制）。
2. **流程画布**（核心，高约 420px，`--bg` 上铺 24px 点阵网格）：
   - 左侧一个 **Claude 节点**：64px 圆形，珊瑚色描边 + 淡底，中间是标志图形，下面写「Claude · 大脑」。
   - 右侧两条横向**泳道**：上为 Codex、下为 CodeBuddy，泳道底色是角色色淡底（极淡，6%），左端有泳道名。只有一个代理时只画一条。
   - 每个子任务是泳道里的一个**节点卡**（宽 220）：子任务名、模型 · 强度（等宽 small）、状态徽章、一排**轮次胶囊** `R1 R2 R3`（每轮一个，颜色＝该轮结论：返工橙、通过绿、运行琥珀、待验收蓝紫）。
   - Claude 节点到每个子任务卡画一条**贝塞尔曲线**：颜色是该子任务代理的角色色，1.5px；运行中的曲线是流动虚线（`stroke-dasharray` 动画）；已通过的为实线；已结束未知状态为 40% 透明。
   - 有返工的子任务卡，右上角画一个**回环箭头**回到卡片左侧，旁边写 `×2` 之类的返工次数，颜色 `--rework`。
   - 节点按开工时间从左到右排，同一泳道放不下就换行；画布可横向滚动。
   - 点击子任务卡 → 打开右侧抽屉。
3. **时间线**（画布下方）：甘特图。每个子任务一行，每轮一段色块（角色色，返工轮的块左边缘带一道 `--rework` 竖线），行首写子任务名；顶部时间刻度；当前时间一条细竖线。悬停色块显示「R2 · 21:40–22:15 · 35 分钟」。
4. **文件列表**（折叠，默认收起）：该任务文件夹里全部文件，按类型分组（规格 / 报告 / 返工单 / 日志 / 其他），点击在抽屉里查看。

### 4.3 子任务抽屉（右侧滑出，宽 min(720px, 92vw)）
- 头部：子任务名、代理徽章（角色色）、模型 · 强度、会话 ID（等宽，可复制）、token（输入 / 缓存 / 输出）。
- 标签页：
  - **对照**（默认）：三栏并排——`规格` / `交付报告` / `返工单`，每栏顶部有轮次切换（R1 R2…）。窄屏改为上下堆叠。Markdown 渲染。
  - **执行过程**：代理每一步的列表，像终端但更好读——每行一个图标（读文件 / 运行命令 / 改文件 / 说话 / 完成）+ 摘要（等宽，单行省略，点击展开）+ 右侧时间。运行中时新步骤从底部出现并自动滚到底（用户上滚时暂停自动滚动）。只有 Codex 子任务有这一页；CodeBuddy 显示「CodeBuddy 结束后才输出结果」并展示 `sum` 摘要。
  - **日志**：原始日志尾部 400 行，等宽。
- `Esc` 或点击遮罩关闭。

### 4.4 账单 `#/bill`
- 顶部：Codex 周额度大环（直径 120）+ 重置时间 + 5 小时窗口额度（如果有）。
- 时间范围切换：今天 / 7 天 / 30 天 / 全部（分段控件）。
- 两张汇总卡：Codex、CodeBuddy 各自的总 token（大数字）+ 输入 / 缓存 / 输出三段细条。
- 表格：任务 × 子任务 × 代理 × 模型 × 输入 × 缓存 × 输出 × 合计，可按任意列排序，数字右对齐等宽，合计行加粗。每行左侧一个角色色圆点。

## 5. 组件规格

- **状态徽章**：高 22，内边距 0 8，圆角 6，状态色淡底 + 状态色文字，左侧 6px 圆点；运行中的圆点呼吸（opacity 1↔.35，1.6s）。文字：运行中 / 待验收 / 返工中 / 已通过 / 中断 / 已结束。
- **代理徽章**：同尺寸，用角色色；文字 Claude / Codex / CodeBuddy。
- **按钮**：高 32，圆角 8；次要按钮透明底 + 边框；图标按钮 32×32。
- **表格**：行高 40，表头 micro 字号 `--text-3`，行间只有底边框，悬停行 `--surface-2`。
- **空状态**：居中一个线条小插画（同标志的三个点，灰色）+ 一句话 + 指引，例如「还没有任务。让 Claude 派一次活，这里就会出现。」
- **加载**：骨架屏（`--surface-2` 块，左右扫光），不要转圈。
- **滚动条**：细（8px），透明轨道，`--border-strong` 滑块。
- 焦点环：2px `--codex`，偏移 2px。所有可点元素可用键盘操作。

## 6. 文案
- 全部中文，口语、简短。时间用相对时间（「3 分钟前」），悬停显示绝对时间。
- 数字：token 用 `1.2M` / `35.6K`，表格里用完整千分位。
- 状态名统一用第 5 节的六个词，不要混用同义词。
